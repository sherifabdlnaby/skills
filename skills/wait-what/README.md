Use `/wait-what` when you didn't follow the agent's last message: too much jargon, names it made up, or no context for where it got to. The agent says it again, point first, in
ASD-STE100 Simplified Technical English and the project's own terms, and shorter than before. It does no new work.

It covers one message. To catch up on everything that happened since your last message, use [`/what-happened`](../what-happened/README.md).
